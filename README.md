# HydStartupArena 🚀
> **One Stop for All Tech Jobs** — Hyderabad Tech Startup Ecosystem & Geospatial Job Portal

Live Interactive Platform featuring real-time cluster map (T-Hub, HITEC City, Gachibowli, Financial District, Madhapur, etc.), verified startup & GCC jobs stream, animated multi-channel application buttons, Light/Dark dual gradient themes, floating background tech logos, and ecosystem analytics.

---

## ✨ Features
- 🗺️ **Geospatial Startup Map**: Interactive Leaflet map with custom markers, live hiring pulses, and company profiles.
- 💼 **Job Discovery & Multi-Channel Apply**: Direct links to Careers portals, HR emails, LinkedIn, Naukri, and Indeed with animated apply buttons.
- 🌗 **Dual Theme Mode**: Glowing orange & purple fading Light Mode + Cyber Emerald Dark Mode with sun/moon transition switch.
- ↔️ **Adjustable Split View**: Draggable resizer divider to customize map vs job listings width ratio.
- 🌌 **Floating Tech Logos Galaxy**: Interactive ambient background with cursor parallax tracking.

---

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: TailwindCSS, PostCSS, Lucide Icons
- **Mapping**: Leaflet + React-Leaflet
- **Data**: Curated Hyderabad startup & GCC ecosystem datasets
